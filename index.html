Why Azure SRE Agent?
🔍

Automated Root Cause Analysis

Multi-layer investigation across apps, platform & infra. Correlates telemetry, tests hypotheses, explains root cause.

⚡

Intelligent Incident Response

Connects to PagerDuty, ServiceNow & Azure Monitor. Automates triage, mitigation and resolution.

🧠

Continuous Learning

Captures knowledge from every incident. Surfaces past resolutions & runbooks in real time. Gets smarter over time.

🛡️

Controlled Automation

Advisory-only or autonomous mode with guardrails. RBAC controls, approval flows, and audit trails built in.

Demo Environment & Sandbox

🧪 Demo Sandbox Repository

Fully automated lab: deploys AKS + multi-service app + SRE Agent with 10 breakable scenarios. One-command deploy, includes Dev Container.

github.com/matthansen0/azure-sre-agent-sandbox →

💥 Breakable Scenarios

Beginner: OOMKilled, CrashLoop, ImagePull, MissingConfig
Intermediate: HighCPU, PendingPods, ProbeFailure
Advanced: NetworkBlock, MongoDBDown, ServiceMismatch

Each scenario shows SRE Agent diagnosing, explaining root cause, and remediating the issue in real time.

⏱️ Demo Quick Start

az login --use-device-code
.\scripts\deploy.ps1 -Location eastus2 -Yes
# ~15-25 min deploy
break-oom # break it
# Ask agent to diagnose!
